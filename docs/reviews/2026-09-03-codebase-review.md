# Codebase review — 2026-09-03

Read-through of everything that changed since the previous review's fix commit (`ae61c75`,
"work the 2026-09-02 codebase review") up to `ad2e84f`: folded single-child folders and indent
guides in the file trees, merge / rebase from the commit context menu, push-after-create in the
Create tag dialog, hunk / line discard, per-file Keep ours / theirs (`conflictSides`), the
Settings dialog (git path, theme, diff context and whitespace defaults), exec-bit mode lines in
hunk / line patches, the file-row context menu with Open / Reveal (`open_path`), and the docs —
`README`s, the split post-v1 smoke checklist, the extended fixture script. Existing code was read
where the new code leans on it (`build_patch`, the index handling in `stage_paths`, `Menu`,
`commitStore`'s selection sync, the merge / rebase state readers).

Four independent passes (Rust · dialogs + settings + commit menu · commit panel + diff · tests +
docs + fixture), findings merged and de-duplicated here — the diff-context mismatch (M1) was found
by all four. Every row was verified at the cited line; the Rust rows that name `git apply` /
`git checkout` behaviour were verified against git 2.55. Triaged and worked the same day; every
row's outcome is in its **Decision** column (four judgment calls — M3, L9, L23, L31 — and one
deferral, P1); frontend 367 / Rust 158 tests afterwards.

Not read: CSS beyond the rules the findings touch, `docs/design/*`, tests except to list gaps.

Severity: **M** = user-visible misbehaviour, data loss, or a smoke-test step that would file a
false bug · **L** = edge case / polish · **P** = performance (no bug) · **H** = hygiene / tests.
