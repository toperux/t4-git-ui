   Settings*; Settings › Updates offered **Update to 0.10.12…**.
2. **U2 a failed check is honest** — pass. Proxy stopped, **Check now** → *couldn't reach GitHub — check the
   connection (error sending request for url (https://github.com/toperux/t4-git-ui/releases/latest/download/latest.json))*.
   No toast, no *up to date*. The earlier offer stayed, as decided 2026-09-25.
3. **U3 Install refused while an operation runs** — pass. A fetch from `slow` (`git fetch --progress --prune
   --end-of-options slow`, upload-pack sleeping ~60 s) in `work`; **Update to 0.10.12…** in `dogfood` → *a git

   then cancelled from the dock.
4. **U4 a failed install unsticks** — pass. Proxy at 150000 B/s, **Update** → *Downloading… 1%*, all three buttons
   disabled; the proxy killed → *the download was interrupted — try again (error decoding response body)*, the bar
   gone, **Check now**, **What's new** and **Update to 0.10.12…** enabled again, still pid 42036.
5. **U5 the install and restart** — pass. Proxy at full speed, both windows open, **Update** at 19:37:23: pid 42036
   was gone and pid 51984 up by 19:37:35 (the download included), running

   the uninstall entry *T4 Git UI 0.10.12*. Both windows came back (`dogfood`, `work`), no badge, and **Check now**
   → *Up to date*. The download's minisign signature verified and the setup ran, under 2.12.0.
