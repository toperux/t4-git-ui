# In-app update walk — installed 0.10.21 → published 0.10.22, 2026-10-08

Decision U1 of `docs/plans/2026-10-08-security-bumps-plan.md`: v0.10.22 ships `rustls` 0.23.45 (Dependabot alert #2),
whose only path into the app is the updater's HTTPS download, and no gate exercises it. This walk is its first real
run. It re-walks smoke group AC's rows *Offered on launch*, *The install* and *Up to date* (all already ticked); the proxy
rows were skipped. Run on the Windows VM over Remote Control, which reported back; nothing was ticked or committed there.

## Setup

- Windows VM, the installed 0.10.21 (`%LOCALAPPDATA%\T4 Git UI\t4-git-ui.exe`, Authenticode valid), launched with
  `smoke-launch.ps1 -Installed` for CDP readings: the real exe, store and updater, CDP's own WebView2 profile.
- Release: [v0.10.22](https://github.com/toperux/t4-git-ui/releases/tag/v0.10.22), run 37686402122, all 16 assets,
  `verify` green.
- The store was backed up first. `recents.json` was seeded with `C:\tmp\t4\work` to reach the toolbar badge.

  `work` → the toolbar badge → Settings › Updates: "Version 0.10.22 is available", **Update to 0.10.22…** enabled.
  **Check now** → "Checking…" → available at 303 ms.
